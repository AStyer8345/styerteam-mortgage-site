## NOTEBOOK_INSIGHTS (cache for future runs if NotebookLM is down)

- **NEW — "outlier absence is the defect" holds only *within one page type*.** A 1/25 FAQPage gap
  looked like a defect until the page turned out to be the cohort's directory hub with no FAQ content.
  Filename pattern is not page type. Before acting on an outlier, ask what the page *is*.
- **NEW — never add schema for content the page does not contain.** FAQPage without visible Q&A is
  fabricated markup and a structured-data violation risk, not an SEO win.
- **NEW — a shell variable inside a double-quoted grep pattern containing `\"` breaks under zsh** and
  returns 0 for every target. `(eval): bad math expression` in the output is the tell. Any per-target
  loop that returns a uniform 0 across *all* targets is a tooling failure until proven otherwise —
  uniform zeros are far more often a broken extractor than a broken site.
- **NEW — reusing a documented rule beats re-deriving it.** I reproduced the *already-recorded*
  `foo/index.html` → `foo/` sitemap normalization false positive by writing a fresh comparison. When
  learnings.md documents a false-positive class, port the fix, don't rewrite the check.
- **NEW — an uncommitted overlay causes real tracking loss, not just blocked cosmetics.** The one page
  that survived the 08-25 GTM restore is exactly the page the overlay had locked. When an overlay
  blocks a batch fix, record *which files were skipped* so the next sweep re-targets them.
- **NEW — verify a commit message's claims against `HEAD`, not the message.** "ship the six queued
  fixes" was true, but it was cheap to confirm all six and it is the confirmation that lets the flags
  be cleared.
- A regex over an HTML attribute must use a backreference for the quote: `(["\'])(.*?)\1`.
- Sandbox-disabled Bash resets cwd; `cd` absolutely in the same command and quote globs.
- Audit `git show HEAD:<path>` when the tree may diverge from `main`.
- "Out of target band" ≠ "defective" — fix what loses information, not what misses a round number.
- For JSON-LD, walk the object graph; `grep` counts are not evidence.
- Match compliance coverage on the identifier (`2653540`), never the prose.
- Uniform absence (0/N) is design; outlier absence (1/N) is the defect — **now qualified, see above**.
- Sandboxed Bash false-returns HTTP `000` — run curl with the sandbox disabled.
- Foreground `sleep` is blocked — write docs between push and live-verify.
- Netlify strips the `netlify` form attribute at build time — verify against committed source.
- Quote-agnostic + extensionless greps on live pages — Netlify Pretty-URLs strip `.html`.
