## NOTEBOOK_INSIGHTS (cached — NotebookLM down 59 runs)

- **Inline-HTML grep is the WRONG instrument for verifying dataLayer event coverage on a JS-driven form binding.** Today's auto-resolution: PM 2026-05-28 NEW finding was based on `curl -L | grep -c 'generate_lead'` against rendered HTML — which returns 0 even when the JS layer pushes `generate_lead` to dataLayer at submit time. The right verification is two-step: (a) inspect the form's class/id list for known binder selectors (`.js-quick-contact`, `#hero-lead-form`, `#contact-form`, `#prequal-form`), (b) grep `script.js` for `dispatchLeadSubmitted()` (or whatever push helper) and confirm that binder is invoked for that selector. Single-step HTML grep is reliable ONLY for inline dataLayer pushes (e.g., `onsubmit="dataLayer.push(...)"`) which is not Adam's pattern. Generalized rule for any future "form X doesn't fire conversion event" finding: do the two-step check before flagging. Costs 1 extra grep, saves a false positive.
