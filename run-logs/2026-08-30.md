## NOTEBOOK_INSIGHTS (cache for future runs if NotebookLM is down)

- **NEW — a link *graph* finds what a link *checklist* cannot.** The rotation's stated check
  ("3 pages, 2+ outbound links each") passed on **all 147** pages. Every real defect was on the
  **inbound** side, which the checklist never asks about. When a checklist item passes trivially
  sitewide, invert the question before moving on.
- **NEW — an orphan is a page the site asks Google to rank but refuses to link to.** Sitemap presence
  + `index,follow` + zero inbound links is a self-contradiction, and it is invisible to every
  page-at-a-time audit. Only a whole-graph pass surfaces it.
- **NEW — before linking an orphan, check whether it is a duplicate.** If the orphan is a near-copy of
  a well-linked page, the correct fix is a canonical (HIGH_RISK, Adam-gated), not a link. Compare body
  text and H2 sets first. All three today came back distinct (0.43 / 0.56 similarity, disjoint H2s),
  which is what licensed linking them.
- **NEW — an `href` regex must strip HTML comments first.** A commented-out template stub produced a
  fake broken link *and*, more dangerously, could manufacture phantom inbound links that hide real
  orphans. After fixing the parser, **re-run the whole analysis** — don't just drop the one finding.
- **NEW — normalize `?query` and `#fragment` off an href before comparing paths.** `href="/x?y=z"`
  does not match `href="/x"`. This produced a "homepage has 0 links to /get-preapproved" finding when
  the true count is 5.
- **NEW — a *selective* zero is more dangerous than a uniform zero.** 08-29's rule was "uniform zeros
  are tooling failures." The sibling case: a zero sitting beside plausible non-zeros looks like a real
  finding and is much more persuasive. Both are tooling until the extractor is tested against a
  known-good case.
- **NEW — don't write a second extractor.** Both of today's false findings came from inline one-off
  regexes written *after* a correct, normalizing extractor already existed in the same session. Reuse
  the good one.
- **NEW — three parallel registries of the same list will desync.** `blog.html` keeps the post list in
  manifest JSON, a noscript `<ul>`, and ItemList schema. Any audit should diff all three as *sets*,
  not spot-check one. The counts matched (59/59/59) while the *contents* differed — equal cardinality
  is not parity.
- **NEW — anchor text should match the destination's `<h1>`, not a stale index title.** Where the two
  disagree, use the page and flag the index.
- A regex over an HTML attribute must use a backreference for the quote: `(["\'])(.*?)\1`.
- Sandbox-disabled Bash resets cwd; `cd` absolutely in the same command and quote globs.
- Audit `git show HEAD:<path>` when the tree may diverge from `main`.
- "Out of target band" ≠ "defective" — fix what loses information, not what misses a round number.
- For JSON-LD, walk the object graph; `grep` counts are not evidence.
- Match compliance coverage on the identifier (`2653540`), never the prose.
- Uniform absence (0/N) is design; outlier absence (1/N) is the defect — **only within one page type.**
- Never add schema for content the page does not contain.
- Sandboxed Bash false-returns HTTP `000` — run curl with the sandbox disabled.
