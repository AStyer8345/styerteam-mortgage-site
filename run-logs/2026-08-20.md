## NOTEBOOK_INSIGHTS (cache for future runs if NotebookLM is down)

- **NEW — check `robots.txt` FIRST, not last, on any sitemap-addition candidate.** A page can pass live-200,
  self-canonical, meta-indexable, good-metadata, inbound-links, *and* the peer-set outlier test and still be
  `Disallow`ed. Every other guard is about whether the page *deserves* to be indexed; robots.txt is about whether
  you already decided it shouldn't be. It's the cheapest check and it's the one that overrides all the others.
- **NEW — the peer-set rule applies to your own writing.** I asserted a disclaimer pattern across 40 pages after
  sampling one, wrote it into a source-of-truth doc, and only caught it because the self-review gate re-verified
  before commit. n=1 is a hypothesis. Verify the set before you publish the generalization.
- **NEW — when the site and a guide disagree, check which one is dated.** The voice guide (2026-03-29) predates
  the Kyber entity change and instructs a license-type that contradicts every page's own legal footer. The
  instinct is to "fix" the 18 pages. The site was right and the instruction was stale.
- **NEW — coverage sweeps must normalize URL form.** Root (`/`) and trailing-slash directory URLs will show up as
  "missing from sitemap" against a naive `/path.html` comparison. 3 of 8 apparent gaps today were this.
- Documentation drift on a compliance claim outranks site drift — the site is the output, the doc is the instruction.
- Verify that documented events actually exist before trusting an event table (`calendly_click` was a phantom).
- A "0 exemptions out of 100" ratio is not automatically a defect — check whether the case is out of selector scope.
- A correct conclusion can rest on false evidence; re-derive the reasoning, not just the verdict.
- Quote-agnostic + extensionless greps on live pages — Netlify Pretty-URLs strip `.html`, rewrite attrs to single quotes.
- An absence is only a defect if the page is actually competing for the query.
- A non-self-canonical URL must never be added to sitemap.xml.
- Schema audits must resolve the type hierarchy, not grep strings: `MortgageBroker` **is** a `LocalBusiness`.
- Uniform absence (0/25) is design; outlier absence (1/25) is the defect — **but robots.txt can veto even that.**
- Don't chase title character counts on pages that are actively ranking.
- Netlify strips the `netlify` form attribute at build time — verify form wiring against committed source.
- Sandboxed Bash false-returns HTTP `000` — run curl with the sandbox disabled.
- Foreground `sleep` is blocked — write docs between push and live-verify.
