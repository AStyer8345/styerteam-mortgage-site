## NOTEBOOK_INSIGHTS (cache for future runs if NotebookLM is down)

*New methodology learning this PM run:*
- **Substring-overlap double-counting in CTA grep audits.** AM's "2 `/get-preapproved` + 2 `../get-preapproved`" on the why-home-prices-arent-crashing blog post was actually a methodology artifact: the relative pattern `../get-preapproved` literally contains the substring `/get-preapproved`, so a bare `grep -o '/get-preapproved'` counted each relative href twice (once for itself, once for the substring match). PM verified the live file has 2 total CTAs (both relative). **Defensive pattern:** when counting href types separately, anchor the regex on `href="` (i.e., `grep -oE 'href="/get-preapproved'` vs. `grep -oE 'href="\.\./get-preapproved'`) to avoid substring overlap. The two counts will then be mutually exclusive. Sum is the true total CTA count.
- **Sitemap lastmod updates within hours of a Netlify push.** Today's AM Tuesday Title+Meta commits at 07:15 + suburb-editor Lakeway R2 at 09:17 — both showing as `2026-05-12` in the sitemap by PM (16h later). Netlify's sitemap is regenerated on deploy and reflects the latest commit timestamps, not the file mtime. Useful for sitemap-freshness verification: a freshly committed page should appear with today's lastmod within ~1 deploy cycle.
