Repeating an `@id` to reference an existing node is **correct** JSON-LD, not duplication. Same for
about.html's `Organization` stub. **Had I reported this, I'd have "fixed" correct markup into worse markup.**

**3. "6 posts missing from the `blog.html` noscript registry" → REJECTED (my own prefix filter).** My
parity check kept only hrefs containing `/blog/`, `/realtor-updates/` or `/resources/`. The six
